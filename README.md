# Crazy Numbers — Interactive Number & Letter Generator

A browser-based JavaScript project by **Shahariar Fahim**. Enter a count and click **Execute** to generate a grid of random numbers and letters with varied visual styles. The total number of generated items appears at the top.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in your browser. No installation required.

## Publish with GitHub Pages
1. Upload `index.html`, `123Counter.js`, `number.css`, and `README.md` to a public GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, `main`, and `/ (root)`, then save.
4. Wait for the deployment link to appear in Pages settings.
